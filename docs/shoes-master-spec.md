# シューズマスタ変換仕様（処理1）

## 1. 参照ブックの分析結果

参照元は `docs/shoes_master.xlsx`。対象範囲と役割は次のとおり。

| シート                               | 範囲         | 役割                                                |
| ------------------------------------ | ------------ | --------------------------------------------------- |
| `（作業用）抽出データ貼り付け＆加工` | `A2:M61765`  | 抽出データの入力（13列、61,763件）                  |
| `（作業用）抽出データ貼り付け＆加工` | `N2:AH61765` | 数式による変換結果（21列）                          |
| `Master Data2026FW②`                 | `A4:U61767`  | 変換結果の貼り付け先                                |
| `部門品種品目マスタ`                 | `A1:K552`    | 性別、年齢区分、競技区分、スパイクの参照表（551件） |

入力13列の見出しは `A:M`、出力21列の見出しは `N:AH` と `Master Data2026FW②!A:U`
で一致する。入力61,763件について固定マスタの未解決キーは0件だった。固定マスタのキーは551件すべて
一意である。

## 2. 入力仕様

- 形式は `.xlsx`、最大20MB。
- 全シートの先頭100行を調べ、A列から次の13見出しが連続する行を入力ヘッダーとして採用する。
- 見出しは前後空白、全角・半角、英字の大文字・小文字を正規化して比較する。
- ヘッダーより下で、A:Mのいずれかに値がある行を変換対象とする。完全な空行は読み飛ばす。

| 列 | 見出し              |
| -- | ------------------- |
| A  | 部門                |
| B  | 部門名              |
| C  | 品種                |
| D  | 品種名              |
| E  | 品目                |
| F  | 品目名              |
| G  | 自社品番            |
| H  | ブランド            |
| I  | スキャンコード(jan) |
| J  | メーカー品番        |
| K  | 商品名(en)          |
| L  | size                |
| M  | sizesys             |

## 3. 変換規則

固定マスタの参照キーは、入力行の `部門 + 品種 + 品目`
を文字列連結して作る。参照表はアプリケーションへ
固定データとして組み込み、アップロードファイル側の参照表や数式には依存しない。

| 出力列 | 見出し                                     | 変換規則                                         |
| ------ | ------------------------------------------ | ------------------------------------------------ |
| A      | BRAND                                      | 入力Hをそのまま転記                              |
| B      | EAN                                        | 入力Iを数字として検証し、13桁未満は左側を0で補完 |
| C      | Manufacturer shoe model ID with color code | 入力Jをそのまま転記                              |
| D      | Commercial name of the shoe                | 入力Kをそのまま転記                              |
| E      | Female, Male, Unisex                       | 固定マスタの性別                                 |
| F      | Adult, Child                               | 固定マスタの年齢区分                             |
| G      | Size                                       | 入力Lをそのまま転記                              |
| H      | SizeSys                                    | 入力Mを文字列として転記。空欄は空文字            |
| I      | Sport category                             | 固定マスタの競技区分                             |
| J      | Season                                     | 空欄                                             |
| K      | Style ID / Model Id / Article              | `入力J + 性別 + 年齢区分` を区切り文字なしで連結 |
| L      | Retailer internal code                     | 入力Gをそのまま転記                              |
| M      | SPIKE                                      | 固定マスタのスパイク値。対象は `✓`、対象外は空欄 |
| N:U    | その他の任意項目                           | 空欄                                             |

`Nothing` は固定マスタに登録された正式な変換値として、そのまま出力する。

## 4. 出力仕様

- 新しいワークブックを作成し、`Master Data2026FW②` シートのみを含める。
- 1～4行目に登録用テンプレートの案内、説明、21列の見出しを配置する。
- データは5行目から値として出力し、数式は含めない。
- 4行目から最終データ行までオートフィルターを設定する。
- 出力名は `<入力ファイル名>_master_data.xlsx` とする。
- 応答ヘッダー `X-Processed-Rows` で処理件数を返し、画面にも件数を表示する。

## 5. エラー仕様

次の場合はファイルを出力せず、画面へ原因を表示する。

- 必要な13列のヘッダーが見つからない。
- データ行が0件。
- 部門、品種、品目が整数ではない。
- `部門 + 品種 + 品目` が固定マスタに存在しない。
- EANが空欄、数字以外、安全に扱えない整数である。
- `.xlsx` として読み込めない、または20MBを超える。

固定マスタ未登録時は、入力シート上の行番号と `部門 / 品種 / 品目` をエラーに含める。変換結果の
欠落を防ぐため、未登録値を空欄へ置き換えて処理を続けることはしない。

## 6. 基準データによる受け入れ条件

- 参照ブックの入力61,763件をすべて変換できる。
- 出力データのA:Uが、参照ブックの `Master Data2026FW②` の5行目以降と一致する。
- 先頭データのEAN `0196222995795` の先頭0が保持される。
- 最終データまで行順を変えずに出力する。
- ログインしていない利用者は変換画面と変換APIを利用できない。
