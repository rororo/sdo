# ピックアップ画面のE2E

```bash
deno install
deno task test:e2e:install # 初回のみChromiumをインストール
deno task test:e2e
```

フロントエンドをビルドし、ローカルのランダムポートで実際のアプリを起動して、
PlaywrightのChromiumで操作する。AWS接続・実環境の認証情報は不要。
S3オブジェクト取得だけを固定CSVへ差し替え、CSV検証、ログイン、HTTP API、アップロード解析、
React画面、Excel生成・ダウンロードは実際の処理を通す。本番S3の最新データやIAMの疎通は対象外。
通常の`deno task test`とは分離している。
失敗時の画面は`e2e/artifacts/pickup-failure.png`に保存する（Git対象外）。
